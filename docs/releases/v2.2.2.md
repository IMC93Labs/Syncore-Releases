## Español

### Cambios

- **Mini Arcade durante la carga:** Snake, Dino Run, Flappy y Breakout, con mando y teclado; récords, último minijuego seleccionado, sonidos opcionales y ambiente de Consola.
- **Lanzamiento:** mejoras de fluidez y transición directa al juego, deteniendo Mini Arcade al entregar el control.
- **Control Center sobre juegos:** corregidos acceso con Guide, posicionamiento y navegación.
- **Frecuencia de pantalla:** confirmación mediante mando, «Cancelar» seleccionado inicialmente y reversión automática a los 15 segundos.
- **Energía y prioridad:** estados reales cuando Windows permite leerlos o modificarlos. El límite de FPS no se ofrece sin backend funcional.
- **Vuelta a Modo Consola:** biblioteca y salida disponibles mientras se comprueban las partidas de forma protegida en segundo plano.
- **Biblioteca:** mejor foco en «Jugar» y «Más acciones».

La actualización directa desde versiones compatibles conserva los datos del usuario; no exige instalar versiones intermedias. Los permisos opcionales de monitorización requieren consentimiento explícito y SYNCORE no permanece elevado durante su uso habitual.

### Limitaciones y seguridad

- **Limitador de FPS no disponible** por ausencia de backend funcional.
- La modificación de prioridad depende de los permisos de Windows y del proceso.
- **DLSS5/ReShade experimental**; composición visual final Native DX12 no certificada ni compatibilidad universal con antitrampas.
- Sensores y temperaturas sujetos a hardware/permisos. **Prueba de cadencia pendiente:** 194 muestras en 30 segundos frente a un mínimo de 200; las lecturas reales siguen disponibles y no se relajó el umbral.
- Instalador sin firma digital: mantén las protecciones de Windows y verifica el SHA-256. Instalación, actualización y rollback físicos en otros equipos pendientes.
- Continúan las limitaciones de «Mostrar escritorio» y diagnósticos históricos CrashReportClient.

### Verificación comunicada en la publicación

**46 pruebas Node, 71 de empaquetado, 3 de runtime y 3 smoke de mandos correctas.** Regresiones C# ejecutadas y expectativas anteriores actualizadas. Estos resultados no certifican pruebas físicas externas.

## English

### Changes

- **Loading-time Mini Arcade:** Snake, Dino Run, Flappy and Breakout, gamepad/keyboard controls, saved high scores and last selection, optional sound and Console ambience.
- **Launch flow:** smoother startup and direct handoff to the game; Mini Arcade stops on handoff.
- **In-game Control Center:** fixes to Guide activation, placement and navigation.
- **Refresh rate:** controller confirmation, Cancel initially selected and automatic rollback after 15 seconds.
- **Power and priority:** actual state where Windows permits reading or changing it. No FPS-limit control without a working backend.
- **Console Mode return:** library and exit stay responsive while save checks continue safely in the background.
- **Library:** clearer focus on Play and More actions.

Compatible stable versions can update directly, retaining user data without intermediate installs. Optional monitoring privileges require explicit consent, and SYNCORE does not run continuously as administrator.

### Limitations and safety

- **FPS limiter unavailable** without a working backend.
- Process-priority changes depend on Windows permissions and the process.
- **DLSS5/ReShade experimental**; final Native DX12 visual composition and universal anti-cheat compatibility are unverified.
- Sensors depend on hardware/permissions. **Cadence test still below target:** 194 samples in 30 seconds versus a minimum of 200; real readings remain available and the threshold was not relaxed.
- Unsigned installer: keep Windows protections enabled and verify SHA-256. Physical install, upgrade and rollback checks on other PCs remain pending.
- Earlier Show Desktop and historic CrashReportClient diagnostic limitations remain.

### Validation reported in the release

**46 Node tests, 71 packaging tests, 3 runtime tests and 3 controller smoke tests passed.** C# regression expectations were updated. These results do not certify external physical testing.
