# SYNCORE Games 2.2.6

## Español

### SYNCORE Games 2.2.6 — estable
- Motor de partidas y recuperación endurecido frente a interrupciones, operaciones pendientes y alternancia entre equipos. Se conservan las copias y el historial ante resultados ambiguos.
- Compatibilidad con los paquetes ZIP que Google Drive clasifica automáticamente; verificación de identidad, ubicación, manifiesto y hashes antes de confirmar contenido.
- Autorreparación cuando reaparece una copia exacta válida, sin confundir revisiones lógicas y paquetes físicos ni saltarse los límites de autorización.
- Seguimiento de juegos más seguro al cancelar una petición de lanzamiento o pasar de un launcher al proceso del juego; la recuperación comprueba primero los procesos activos.
- Correcciones de respuestas tardías del selector visual, estados de carga de biblioteca, cierre a bandeja y acciones de Drive en ventanas pequeñas.

### Actualización y conexión de Drive
La actualización conserva la cuenta conectada, su configuración y las credenciales cifradas del mismo usuario de Windows. No hace falta desconectar ni volver a vincular Drive para actualizar. Una revocación de Google o un cambio de usuario de Windows puede requerir autorización de nuevo; las credenciales no se copian de un PC a otro.

Actualiza desde la instalación oficial o ejecuta **SynCore-Setup-v2.2.6.exe** sobre la instalación existente, con el mismo usuario habitual. Cierra antes las copias de prueba mediante Salir. No desinstales ni elijas eliminar datos para actualizar. El instalador solicita UAC; SYNCORE no se ejecuta permanentemente como administrador.

### Validación y límites
La candidata anterior superó 1.499 casos de regresión, 899 contra su paquete, 287 dirigidos y 36 de Core/Legacy; las selecciones se solapan. Drive real superó 15 fases con dos perfiles aislados en un único PC, incluida divergencia concurrente y restauración original, además de la recuperación en otro proceso tras una salida abrupta. La compilación final supera 991 pruebas sobre el paquete, una selección de 94 del actualizador/autorización (incluidas 9 de conservación DPAPI), 36 de Core/Legacy, 48 de empaquetado/runtime y 3 contratos seguros de componentes. Las selecciones se solapan. La conexión real de solo lectura funciona antes y después con los mismos archivos de credenciales cifrados.

**La prueba entre dos PC físicos queda pendiente tras actualizar ambos equipos.** Los cortes de red fueron inyectados y no se probó un apagado eléctrico real. No se promete ausencia absoluta de errores. No se ejecutó el instalador sobre el perfil habitual durante la publicación.

El instalador no está firmado digitalmente. Descarga de este repositorio y comprueba el SHA-256. RGB SOYO y NR conservan sus limitaciones y validaciones físicas pendientes; no se anuncian como compatibilidad universal.

## English

### SYNCORE Games 2.2.6 — stable
Save synchronization, durable recovery, launcher process tracking and common UI flows have been hardened. Valid ZIP packages classified by Drive are accepted while identity, location, manifest and hash checks remain enforced. Exact-source automatic repair preserves authorization budgets and logical/physical revision identities.

Updating preserves Drive configuration and encrypted credentials for the same Windows user; do not disconnect Drive or uninstall/delete local data to update. Google revocation or a different Windows user can require authorization again. Credentials are not transferred between PCs.

Update the official installation with **SynCore-Setup-v2.2.6.exe**, using your usual Windows account. Exit test copies first. UAC applies to Setup; the application is not permanently elevated.

Real Drive completed 15 phases using two isolated profiles on one physical PC, plus abrupt-process recovery. **Two-physical-PC validation remains pending after both installations are updated.** Network faults were injected; physical power loss was not tested. Prior candidate checks and additional updater/DPAPI release checks do not guarantee zero bugs. No installer was executed against the habitual profile by the publisher.

Unsigned installer: verify its source and SHA-256. Existing SOYO RGB and NR experimental limitations remain unchanged.
