## Español

### Cambios incluidos
- Ajustes y Control Center del Modo Consola más compactos y legibles, secciones inicialmente contraídas y selectores verticales con confirmación/cancelación mediante mando.
- Navegación circular y repetición continua; patrón de vibración de inicio y tarjetas de mando compactas con información real de batería/conexión.
- Pulido de detalles de juego y fichas de biblioteca, conservando carátulas completas, acciones, favoritos y servicios existentes.
- Control Center recibe lecturas CPU/GPU, temperaturas, RAM y VRAM sin juego y aunque el OSD esté desactivado. FPS/frametime requieren un renderer compatible. Los interruptores solo controlan su aparición en el OSD.
- Select + Start alterna Own usando la misma preferencia que el Control Center; la captura Own sigue usando PresentMon, sin exigir RTSS.
- Temperatura CPU mediante el broker existente y sensores compatibles; instalación opcional del proveedor PawnIO oficial firmado.
- Setup incluye autorización ETW opcional, explícita y reversible para el usuario local. Puede requerir cerrar sesión y entrar de nuevo; no eleva SYNCORE ni solicita UAC por juego para medir.

### Actualización y conservación de datos
Actualización directa mediante el instalador habitual, sin versiones intermedias, desde versiones compatibles 2.0.0, 2.1.0, 2.1.1 y 2.2.0. Se mantiene la identidad de instalación y se conservan biblioteca, configuración, vinculación, partidas, historial y respaldos. La desinstalación normal conserva los datos; eliminarlos requiere una elección destructiva separada. Mantén respaldos independientes antes de actualizar.

Las versiones anteriores permanecen publicadas e intactas. No se instala ninguna actualización automáticamente sin confirmación.

### Pruebas
- 2,856 casos C# únicos correctos tras batería completa y reejecución de contratos de interfaz actualizados; 1 omitido porque requiere escritura autorizada en Drive real.
- 46 pruebas Node y 71 de empaquetado correctas. Ningún fallo pendiente en los casos ejecutados.
- Actualizadores binarios 2.0.0, 2.1.0, 2.1.1 y 2.2.0 detectan directamente 2.2.1 en un feed aislado; no se ejecuta el instalador sobre el equipo habitual.

### Integridad y requisitos
- Windows 10/11 x64; NTFS donde se utilicen junctions.
- Runtimes, helper/broker, PresentMon y dependencias necesarias incluidos. Las funciones opcionales y permisos se explican en Setup.
- Instalador, `update.json`, SHA256 y `PUBLIC-PROVENANCE.json` disponibles como assets.
- **Instalador SYNCORE sin firma digital.** No desactives protecciones de Windows; verifica origen y SHA256. Las dependencias firmadas no firman el instalador de SYNCORE.
- El tag es de distribución: la procedencia declara una congelación verificable del árbol funcional con cambios locales, no una equivalencia a un commit fuente limpio.

### Funciones pendientes o limitadas
- Limitador FPS dinámico no disponible; su selector permanece deshabilitado.
- Own observa eventos Present: no certifica por sí solo los fotogramas finalmente mostrados o generados.
- DLSS5 conserva las rutas existentes; Native DX12 tiene evaluaciones internas verificadas, pero su composición visual final no está demostrada. No se anuncia compatibilidad universal ni con antitrampas.
- ReShade oficial puede mostrar su aviso de inicio; no se parchean sus DLL para ocultarlo.
- Algunos accesos de Mostrar escritorio siguen pendientes. La entrada Añadir juego con mando está reservada para un flujo futuro.
- Temperaturas y ETW dependen del hardware, sensores y políticas del equipo; se muestra — si no existe lectura fiable. Configurar ETW permite trazas de rendimiento al usuario y sus aplicaciones y puede requerir nuevo inicio de sesión.
- Diagnósticos históricos CrashReportClient documentados y respaldados; no son partidas.
- Instalación limpia, actualización, reinstalación y rollback físicos en otros equipos pendientes de validación externa. Las pruebas automatizadas y los casos reales previos no sustituyen esa comprobación.

## English

### What changed

- More compact, readable Console Mode settings and Control Center, with initially collapsed sections and controller-friendly confirm/cancel choices.
- Wraparound navigation, repeat behaviour, startup controller vibration and compact controller/battery information.
- Game details and library refinements while preserving existing covers, favourites and actions.
- Live CPU/GPU, temperature, RAM and VRAM readings can appear in Control Center even without a running game and with OSD switched off; FPS/frametime still need a compatible game renderer.
- The Select + Start shortcut uses the same preference as Control Center for the integrated PresentMon-based OSD, without requiring RTSS.
- Compatible CPU sensors use the existing broker; the signed official PawnIO provider is an optional installation choice.
- Optional, explicit and reversible ETW permission during Setup for the local user; it may require sign-out/sign-in and does not elevate SYNCORE for routine game telemetry.

### Updates and data

Compatible stable versions **2.0.0, 2.1.0, 2.1.1 and 2.2.0** can update directly to 2.2.1. Existing library, settings, credentials, saves, history and protected backups are intended to be preserved. Normal uninstallation retains user data; removing data requires a separate destructive choice. Keep independent backups. Previous releases remain published and intact.

### Verification

- **2,856 C# cases passed** and 1 skipped because it needs authorised access to a real Drive account.
- **46 Node tests** and **71 packaging tests** passed.
- Legacy updater binaries detected 2.2.1 from an isolated test feed; the normal installed application was not updated during those checks.

### Distribution and requirements

- Windows 10/11 x64; NTFS where junction-based protection is used.
- Required runtimes, broker/helper, PresentMon and bundled dependencies.
- Release assets include the installer, `update.json`, SHA-256 and `PUBLIC-PROVENANCE.json`.
- **The SYNCORE installer is not digitally signed.** Keep Windows protections enabled; verify the release origin and SHA-256. Signed vendor components do not sign SYNCORE itself.
- The distribution tag identifies a verified functional-tree freeze with recorded local changes, **not** a promise that every file matches a clean source commit.

### Known limitations

- The dynamic FPS limiter is unavailable and its selector remains disabled.
- PresentMon reports Present events, not verified final displayed/generated frames.
- DLSS5 integration remains experimental and game-specific; Native DX12 final visual composition is unconfirmed. No universal anti-cheat compatibility claim is made.
- The official ReShade startup notice may appear; DLLs are not patched to suppress it.
- Some Show desktop paths remain unresolved; controller-native Add game is reserved for a future wizard.
- Sensors, ETW and temperature availability depend on the hardware and user permissions. Unavailable values show a dash rather than invented measurements.
- Historic CrashReportClient diagnostics are documented and backed up; they are not game-save data.
- Clean install, update, reinstall and rollback on additional physical PCs still require external validation.
