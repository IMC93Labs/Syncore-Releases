# SYNCORE Games 2.2.4

## Español

### SYNCORE Games 2.2.4
- Iluminación RGB frontal **experimental**, opcional y desactivada por defecto, para la barra SOYO B650 ITX comprobada: panel compacto, paleta de color, brillo, velocidad progresiva, escenas y vista previa antes de guardar. No necesita OpenRGB abierto. Strobe se retira porque comparte el comando de Respiración.
- Selector de efectos simplificado: Apagado, Fijo, Respiración, Cycling, Rainbow, Spring y Water. Se conservan los identificadores de preferencias anteriores.
- Cuenta conectada de Google Drive visible en Ajustes y Nube automática.
- Los juegos importados sin instalación local se distinguen de errores de transferencia. Una verificación de paquete pendiente se indica como pendiente, sin confirmar sincronización ni ocultar conflictos reales.
- Correcciones ya comprobadas de conexión y recuperación Cloud incluidas en la candidata de partida. Se mantienen verificación de integridad, CAS y versiones protegidas.

### Límites conocidos
RGB no es universal. Los modos y velocidades dependen del controlador. Sigue pendiente validar físicamente esta última combinación y resolver la pérdida intermitente de respuesta observada en pruebas anteriores; no se da por solucionada. Cierra OpenRGB antes de usar el control de SYNCORE; puedes dejar RGB desactivado. El mínimo de velocidad está limitado por el protocolo del dispositivo.

No se certifica que el PC remoto carezca de incidencias Cloud: los errores reales permanecen visibles y no se alteran partidas para borrar un aviso. NR continúa experimental, sin prometer compatibilidad universal, mejora visual en todos los juegos ni certificación general en RTX 50. El limitador dinámico FPS y las limitaciones anteriores siguen pendientes.

Instalador **sin firma digital**. No desactives las protecciones de Windows. Se mantienen los datos durante actualizaciones; no se ha realizado una instalación física de esta versión durante su publicación. La prueba externa de instalación/actualización queda pendiente. No se cambian permisos opcionales silenciosamente.

## English

### SYNCORE Games 2.2.4
- Optional, disabled-by-default **experimental** front RGB control for the tested SOYO B650 ITX strip: compact panel, colour palette, brightness, progressive speed, scenes and preview before saving. OpenRGB must be closed. Strobe is removed because it shares Breathing's command.
- Simplified effects: Off, Static, Breathing, Cycling, Rainbow, Spring and Water; existing stored effect identifiers are preserved.
- Connected Google Drive account displayed in Settings and Automatic Cloud.
- Imported games without a local installation are distinguished from transfer errors. Pending package verification remains pending, without claiming sync or hiding actual conflicts.
- Previously checked Cloud connection/recovery fixes from the approved test candidate are included. Integrity verification, CAS checks and protected versions remain enabled.

### Known limitations
RGB is hardware-specific. Physical validation of this latest UI/backend combination and resolution of the intermittent loss of response seen in earlier tests remain pending. RGB can stay disabled. The minimum speed is limited by the device protocol. Real Cloud issues are not cleared by altering saves. NR remains experimental, without universal compatibility/visual-improvement or general RTX 50 certification. Dynamic FPS limiting and previously documented limitations remain.

**Unsigned installer**: keep Windows protections enabled. External installation/update validation is pending; no physical installation was run during publication. Optional permission changes still require consent.
