# SYNCORE Games 2.2.5

## Español

### SYNCORE Games 2.2.5
- Verificación automática en segundo plano de paquetes Current pendientes al iniciar u obtener conexión con Drive. Reutiliza el verificador existente, contrasta identidad/manifiesto/hashes y vuelve a comprobar el estado antes de registrar una copia local verificada. Las llamadas simultáneas se agrupan; no se sustituyen partidas ni se publica contenido en Drive para realizar esta comprobación.
- El resultado actualiza Nube automática. Si no se puede verificar, se conserva el pendiente y se muestra la causa; no se anuncia sincronización sin pruebas.
- Correo de la cuenta conectada visible también en Almacenamiento, conservando el equipo y la ocupación del disco.
- Buscar actualizaciones y Actualizar llevan a Acerca de para consultar estado y progreso.
- Las copias de prueba/portátiles informan ANTES de descargar de que no pueden actualizar la instalación oficial. Los errores de preparación quedan visibles y diagnosticados.
- El aviso de actualización deja de depender del estado persistente de transferencias cuando su ventana está oculta y se mantiene pendiente si Windows pasa a ocupado. Se conservan Más tarde, No molestar y la protección frente a interrupciones de juegos.
- Aislamiento de las pruebas del actualizador: sus diagnósticos utilizan directorios temporales, sin añadir líneas sintéticas al log habitual.

### Importante para actualizar
Cierra las copias de prueba mediante Salir y abre la instalación oficial (`C:\Program Files\SYNCORE\SynCore.exe`) para actualizarla. Una versión antigua que ya esté abierta en una carpeta test-release sigue ejecutando su código antiguo: publicar 2.2.5 no modifica esa copia. El instalador sigue solicitando UAC y requiere consentimiento; no se ejecuta SYNCORE permanentemente como administrador.

### Límites y validación
Las comprobaciones automáticas no sustituyen la prueba física de actualización ni certifican el estado concreto de todos los PCs. El instalador no se ejecutó durante esta publicación. Si hay divergencia real, falta de permisos o daño verificable, las protecciones y el pendiente se mantienen.

RGB SOYO sigue experimental y conserva su validación física pendiente, incluida la pérdida intermitente de respuesta anterior. NR mantiene sus limitaciones documentadas; no se promete compatibilidad universal. Instalador **sin firma digital**: verifica procedencia y SHA-256; no desactives las protecciones de Windows.

## English

### SYNCORE Games 2.2.5
- Pending Current packages are automatically verified in the background after startup or a verified Drive connection. The existing verifier checks identity, manifests, hashes and current state before registering a verified local copy. Concurrent requests are coalesced; this verification does not replace saves or publish content to Drive.
- Automatic Cloud is refreshed after verification. Unresolved checks retain their pending state and cause; synchronization is never claimed without evidence.
- The connected account is now also displayed in Storage, alongside the device and disk usage.
- Check for updates and Update navigate to About for status and progress.
- Test/portable copies explain BEFORE downloading that they cannot update the official installation. Preparation failures remain visible and are diagnosed.
- Update notices no longer wait indefinitely on persistent transfer state after its popup is hidden, and remain queued if Windows becomes busy. Later, Do Not Disturb and game interruption safeguards are preserved.
- Updater tests write diagnostics only to isolated temporary directories.

### Updating and limitations
Exit test copies and open the official installation (`C:\Program Files\SYNCORE\SynCore.exe`) to update it. Publishing 2.2.5 cannot change code already running in an older portable/test copy. UAC still requires consent. External physical installation/update validation and verification of each PC's actual state remain pending; the installer was not executed during publication. Actual conflicts, permission problems and integrity failures are not hidden.

SOYO RGB remains experimental with outstanding physical validation, including the earlier intermittent loss of response. NR retains its documented limitations without universal compatibility claims. **Unsigned installer**: verify its origin and SHA-256 and keep Windows protections enabled.
