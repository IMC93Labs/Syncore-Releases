## Español

### SYNCORE Games 2.2.8 — estable

- Nueva opción **Ajustes → Google Drive → Más opciones → Ampliar permisos de Drive** para gestionar archivos añadidos desde Drive Desktop u otras aplicaciones. Google solicita autorización explícita para acceder a toda la cuenta; la conexión normal mantiene sus permisos limitados.
- La ampliación conserva la conexión anterior hasta verificar la misma cuenta y la misma carpeta raíz. Cancelar o fallar no desconecta Drive. Las reconexiones recuerdan el permiso ampliado ya elegido para ese cliente OAuth.
- El borrado vuelve a comprobar el juego y su ubicación. El catálogo utiliza una revisión condicional para conservar los cambios concurrentes del otro PC. Un permiso insuficiente mantiene la operación pendiente y explica la acción necesaria.
- Esta revisión conserva y verifica la raíz existente al reconectar con acceso ampliado. La actualización mantiene las credenciales cifradas del mismo usuario de Windows.
- La auditoría de historial deja de generar el aviso obsoleto de un juego cuyo borrado remoto ya está confirmado. Solo se retira ese aviso de memoria; se conservan el historial local y las comprobaciones de juegos activos o borrados pendientes.

### Instalación y permisos

Instala **SynCore-Setup-v2.2.8.exe** sobre la versión existente, con tu usuario habitual. No desconectes Drive ni elimines datos locales para actualizar. Al terminar una instalación manual, cierra Setup y abre SYNCORE desde su acceso directo normal. El actualizador integrado conserva su reinicio independiente.

Amplía permisos únicamente mediante la opción indicada si necesitas gestionar archivos que se añadieron fuera de SYNCORE. Google pide tu consentimiento; puedes cancelar sin sustituir la conexión anterior.

## English

### SYNCORE Games 2.2.8 — stable

An explicit **Settings → Google Drive → More options → Expand Drive permissions** action enables management of files added through Drive Desktop or other applications. Google asks for consent to full-account Drive access; normal connections retain file-scoped permissions.

The previous connection remains active until the same account and existing root folder are verified. Cancellation or failure preserves it, and later reconnections remember the broader permission already selected for that OAuth client. Deletion rechecks the selected game and location; conditional catalog writes preserve concurrent changes from another PC. Insufficient permissions leave the operation pending with an actionable message.

History audits no longer recreate the stale notification for a game whose remote deletion is confirmed. Only that in-memory notice is cleared; local history and checks for active games or pending deletions are retained.

Install **SynCore-Setup-v2.2.8.exe** over the existing installation using the same Windows user. Do not disconnect Drive or delete local data. After manual Setup finishes, open SYNCORE through its normal Windows shortcut. Encrypted credentials and the integrated updater's independent restart are preserved.

Validation passed **404 targeted C# Drive, deletion, recovery and history cases** and **26 Python packaging contracts**. This revision was installed and its broader Drive authorization checked on two physical PCs. A real synthetic external-file test verified HTTP 204 deletions followed by HTTP 404 absence checks, while retaining local copies. All 467 real save files checked on PC A were unchanged. The earlier two-PC A1/B2 exchange was validated with 2.2.7; no physical power-cut test was performed.
